# IT Learning Journal

This isnt going to be my projects repo. If you're looking for code, deployed apps, CTF writeups or labs and such, they'll live elsewhere as I build them.

This repo is a running log of my professional development and proof that I'm 
consistently doing the work and such. Weekly entries covering what I studied,
what I completed, what confused me, what I'm doing about it and any hiccups 
along the way.

## Why this exists

Honestly? I just like doing this stuff. This journal is mostly me keeping track of what I'm learning so I don't lose my work and i have something to look back too, kind of like a half lab notebook. It also doubles as a decent paper trail for my own professional delopment, but really the goal is to keep showing up here consistently :)
